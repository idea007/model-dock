# 接入端 demo

[English](client-demo.md) | **简体中文**

这是一个独立的接入应用：后端持有 **项目密钥**，浏览器管理应用功能。它通过网关的公开推理接口接入，不调用管理接口。demo 是可运行的接入示例，不是网关运行依赖，也不是多用户生产应用。

## 先体验模拟模式

```sh
npm run demo:mock -- --open
# 安装本地打包产物后也可以使用：
model-dock-demo --mock --open
```

默认地址是 `http://127.0.0.1:4318`。`--open` 使用 URL fragment 携带 demo 本地会话令牌，页面载入后立即移除。手动获取令牌可运行 `npm run demo -- token --mock`。

模拟模式在临时本机端口启动隔离网关，提供 `demo-chat`、`demo-reasoner` 两个固定响应模型及专用项目密钥。它不读取个人网关配置，也不调用真实或付费模型。页面和响应明确标记模拟，不伪造 Token 用量。关闭后临时网关会清理，应用偏好独立保留。

示例包含独立的自由对话、结构化提取；「内容处理」分组含摘要、润色、翻译；「开发助手」分组含代码讲解与审查。模拟回复用于体验传输和控制，不执行真实推理任务。

## 连接真实 Model Dock

```sh
# 终端 1：模型供给、发布和项目权限
npm start -- --open
# 终端 2：接入应用
npm run demo -- --open
```

1. 在服务端「模型与服务」发布模型，在「项目访问」创建限定模型范围的密钥。
2. 打开 demo 的「网关接入设置」，填写 API 地址（通常为 `http://127.0.0.1:4317/v1`）及 `md_key_…` 项目密钥。管理员令牌会被拒绝。
3. 启用此应用需要的授权模型，配置功能并保存。
4. 在「应用体验」用默认模型或明确选择的候选运行功能。真实请求会使用所选上游的资源与额度。

发送给网关的是模型 ID，不是应用功能 ID。撤销密钥、模型不可用、默认选择失效或思考等级不合法时会明确失败，不会自动换模型或重试。停止流式输出会取消网关请求。详见 [功能与模型设置](model-settings.zh-CN.md)。

可用 `--port 4328` 指定 demo 端口。从模拟切换到真实模式时，先停止占用 4318 的 demo，或给新进程指定不同端口。网关与应用可以独立重启。

## 数据边界

| 所属 | 默认目录 | 内容 |
| --- | --- | --- |
| 服务端 | `~/.model-dock` | 上游凭证、模型发布、项目权限及兼容的旧别名 |
| 接入端 | `~/.model-dock-demo` | `client.json` 中的网关地址、项目密钥、目录缓存和应用偏好；本地会话令牌与单写者锁 |
| 模拟接入端 | `~/.model-dock-demo/mock` | 模拟模式专用的独立应用设置 |

`MODEL_DOCK_DEMO_HOME` 可改变接入端根目录。demo 自己执行版本检查和原子写入；项目密钥存于本地后端私有文件，文件权限 `0600`、目录 `0700`，**未加密**，不会通过状态接口返回或写入浏览器存储。浏览器使用独立的 demo 会话令牌。Windows 请使用当前用户私有目录并设置相应 ACL。不要提交这些数据目录。

更换网关地址或项目密钥后，应用中的模型会关闭，保留原选择供复核。`--mock` 每次启动都会使用新的隔离模拟网关；真实接入请使用普通模式及其独立目录。

## 接入端接口

这些接口属于 demo 进程，除静态资源与 `/healthz` 外需要 demo 会话令牌、同源访问，POST 使用 JSON。它们与网关管理接口相互独立。

- `GET /api/state`：不含密钥的应用状态。
- `POST /api/connection`：提交 `revision, baseUrl, apiKey`，读取并连接授权目录。
- `POST /api/refresh`：提交 `revision`，刷新目录并保留失效选择。
- `POST /api/settings`：提交 `revision, models, routes`，原子保存完整草稿。
- `POST /api/run`：提交 `featureId, prompt` 及可选的 `modelId, reasoningEffort, stream`，解析功能后向网关发送 JSON/SSE 请求。

内部字段 `routes` 沿用旧命名，表示应用功能列表，不会发送给网关管理接口。完整字段与代码入口见 [英文接口说明](client-demo.md#demo-local-api)。
