# 接入端的功能与模型偏好

[English](model-settings.md) · [接入端 demo 启动说明](client-demo.zh-CN.md)

「功能与模型」已迁入默认运行在 **4318** 端口的独立接入端 demo。**4317** 的服务端管理台负责模型发布和项目授权。接入端保存设置不会修改服务端模型开关、项目权限或其他应用的配置。

## 视图与草稿

- 「按凭证」展示授权目录、模型能力、应用模型开关、思考深度、独立功能与可展开的分组。
- 「按功能」展示可展开的功能分组及独立功能。
- 搜索覆盖来源、模型、功能名称与 ID、分组名，筛选不会删除草稿中的隐藏配置。
- 列宽支持拖动、双击重置，也支持聚焦后用方向键调整；Shift 加大步长，Home 重置。两种视图分别记忆列宽。

更改先保存在当前标签页草稿，点击「保存更改」才生效。切换视图或刷新同一已认证标签页可以恢复草稿；退出会话会清除草稿。「撤销更改」载入最新设置。多标签页产生版本冲突时，保存整体失败并保留草稿。

无草稿时，「刷新目录」通过项目密钥读取网关模型列表；新授权模型默认不在此应用启用。失去授权的模型及其选择保留并标记不可用。有草稿时刷新只检查应用设置版本，保存或撤销后再更新网关目录。

## 独立功能与功能分组

功能 ID 属于接入应用，例如 `summarize` **不是网关模型别名**。demo 在后端将功能解析为授权模型 ID，再向网关发送请求。每个功能选择一个明确的演示提示模板。

分组留空即独立功能；填写分组名可组织相关功能。分组与模型选择方式相互独立：

- **单一模型**：勾选一个模型会替换之前的选择，同时设为默认；取消勾选后功能未配置。
- **多个候选 + 默认模型**：先勾选候选，再单独指定默认。移除或停用默认模型后保留其选择并提示不可用，不会自动换模型。运行时可以明确选择其他可用候选。

分组勾选会把一个模型加入所有兼容子功能，或从这些子功能中移除。单模型子功能以它为唯一和默认模型；多模型子功能保留各自的默认选择。只选择了部分兼容子功能时显示半选状态。

应用模型开关只决定此应用是否使用模型。服务端模型发布与项目密钥权限会在每次请求时继续校验。

## 思考深度

只有授权目录声明了思考等级才显示控件。未声明的能力保持未知；目录可见不等于上游账号一定拥有推理权限。

1. 在模型列设置此应用允许的思考等级，至少保留一个。
2. 点击分组行的等级名称切换可选状态，点击独立图钉指定默认。
3. 展开分组后可为子功能及当前模型覆盖设置；「恢复继承」移除覆盖。独立功能直接继承应用模型设置。

继承顺序为 **模型 → 分组 → 功能/模型覆盖**。缩小父级允许范围会同步收窄显式子级设置；被移除的思考默认值优先降为剩余较低等级，否则选剩余最低等级。这些修改显示在草稿中，保存后生效；模型选择本身不会自动替换。

运行时由 demo 后端校验有效范围、补充默认值，再把思考参数传给网关。没有应用偏好时使用目录声明的默认值，否则交给上游。目录变化导致旧设置不再有效时，需要重置旧思考设置或明确选择有效等级。

## 旧服务端别名

旧网关别名及其思考策略保留兼容，已有项目权限与调用继续有效，可通过管理员状态接口查看。`POST /admin/routes` 不再创建全局业务别名，返回 `410 client_owned_settings`。demo 不会自动读取管理员配置或导入旧别名；迁移已有应用时，请用授权的原始模型 ID 在应用内重建功能。
